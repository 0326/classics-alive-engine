# Asset guidelines

Treat assets as content with provenance, not as anonymous files. Every background, character, audio item, and placeholder has a stable ID, type, dimensions or duration, license/source, and status (`placeholder`, `draft`, `reviewed`, `released`).

Before generating art, describe the period, geography, material culture, camera framing, lighting, and exclusions. Do not use a modern object as a silent substitute for an ancient one. Keep prompts and source notes next to the asset manifest so a later Agent can reproduce or revise the visual language.
